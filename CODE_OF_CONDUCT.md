# Code of Conduct

LicenseGuard is a small security and compliance project, so discussions should stay respectful, practical, and focused on improving the tool.

## Expected behavior

- Be respectful of different experience levels, backgrounds, and viewpoints.
- Keep feedback specific, constructive, and related to the work.
- Assume good intent, but accept corrections when something lands badly.
- Report security-sensitive issues privately by following `SECURITY.md`.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publicly sharing private security reports before maintainers have had time to respond.
- Personal attacks, repeated disruption, or intentionally misleading reports.

## Enforcement

Maintainers may edit, hide, or remove comments and issues that violate this code. Repeated or serious violations may lead to being blocked from participating in the project.

If you see a problem, open a private security advisory for security matters or contact the maintainer through the repository owner profile for conduct matters.
